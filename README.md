# Onestrand Business Suite

Eine local-first Plattform für Schweizer Kleinbetriebe mit 1 bis 20 Personen, die bei der Digitalisierung zurückliegen. Aus einer gemeinsamen Plattform entstehen installierbare Apps für iPhone, iPad und Web, je für eine Arbeitsweise: Gastronomie (Randen), Arbeit am Objekt der Kundschaft (Reinigung, Hauswartung, Maler, Dach, Umzug, Haustechnik, Garten), kleine Hotels, Termine und Kurse (Coiffeur, Fitness).

Ohne Konto, ohne Server: Die Daten bleiben auf den Geräten des Betriebs. Offerten, Rapporte, Rechnungen mit QR-Zahlteil, Stunden, Belege und Checklisten an einem Ort, in der Sprache der Branche.
